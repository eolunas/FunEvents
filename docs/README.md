# Documentación

Todo el punto 1 de la prueba —arquitectura, decisiones y diagramas— y la guía de ejecución del punto 2 están en **[`index.html`](index.html)**, un único documento HTML autocontenido.

- **Publicado:** <https://eolunas.github.io/FunEvents/>
- **En local:** abre `docs/index.html` en el navegador. No necesita servidor ni build.

## Contenido

| Sección | Qué cubre |
|---------|-----------|
| 1 | Contexto, canales y el requisito que condiciona el diseño |
| 2–3 | Estilo arquitectónico (C4 contexto y contenedores), capas y módulos |
| 4 | API, contrato de errores y versionado |
| 5 | Concurrencia — el núcleo del problema |
| 6 | Idempotencia |
| 7 | Modelo de datos |
| 8 | Ciclo de vida y caducidad |
| 9 | Seguridad: API Key, permisos, aislamiento y límite de peticiones |
| 10–11 | Escalabilidad y observabilidad |
| 12–13 | Plan de evolución y doce ADR |
| 14 | Alcance declarado |
| 15–18 | Ejecución del prototipo, demo, datos sembrados y pruebas |
| 19 | Trazabilidad del enunciado a la solución |
